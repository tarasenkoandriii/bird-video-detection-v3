# Bird Video Detection v3

Публічний репозиторій набору v3. Пілот і повний корпус збережені окремо, у форматі YOLO: `train/images`, `train/labels`, `val/images`, `val/labels`.

## Структура

- `pilot/` — 84 послідовні кадри з 7 відео, окремий перевірений пілот; повний маніфест — `pilot/manifest.json`.
- `train/`, `val/` — повний корпус із 14 118 кадрів із 7 відео.
- `data.yaml` — конфігурація YOLO для повного корпусу; `pilot/data.yaml` — для пілота.
- `corpus_frame_index.jsonl` — індекс кадрів, джерело, SHA-256, розмір і первинна рамка трекінгу.
- `proposals_video_focus.jsonl`, `proposals_coco.jsonl` — пропозиції рамок двох детекторів із координатами та впевненістю.
- `splits.json` — розбиття за цілими послідовностями, без перемішування кадрів між train і val.
- `AUDIT.md` — обсяг і обмеження перевірки.

## Отримання зображень

Зображення LaSOT не включені до цього репозиторію. Завантажте оригінальний набір через офіційну сторінку LaSOT і розмістіть кадри відповідно до шляхів у `corpus_frame_index.jsonl`; скрипт `prepare_local.py` перевірить наявність джерела й відновить YOLO-дерево. Умови джерельного набору поширюються на зображення.

Офіційне джерело: https://vision.cs.stonybrook.edu/~lasot/

## Статус розмітки

`pilot/` має статус асистентської візуально перевіреної розмітки для 84 кадрів; незалежного підпису людського анотатора немає. Розмітки повного корпусу — **кандидати детектора `video_focus.pt`**, не затверджена ground truth. Рамки незалежного COCO-детектора доступні окремо для аудиту. Не використовуйте повний корпус як фінальний benchmark без ручної перевірки.

Клас: `0 = bird`.
